# Security Policy

## Reporting a Vulnerability

Report privately, not via a public issue:

- **Preferred**: https://github.com/agapasieka/resume/security/advisories/new
- **Email**: agi.pasieka@outlook.com

## Scope

This is a static personal CV site (HTML/CSS) plus a small GitHub Actions
workflow that renders the page to PDF and emails it. In scope: anything in
this repo's code or workflows that could expose secrets or be abused to run
unauthorized code/emails.

Out of scope: the visible resume content itself (name, job history, links)
— that's meant to be public.
